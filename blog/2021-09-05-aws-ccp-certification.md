## About

Certification `Professional Scrum Master™ I`, also known as `PSM I`.

The definition of certification is as follow:

> The AWS Certified Cloud Practitioner validates foundational, high-level understanding of AWS Cloud, services, and terminology.
> 
> This is a good starting point on the AWS Certification journey for individuals with no prior IT or cloud experience switching to a cloud career or for line-of-business employees looking for foundational cloud literacy.

## Tips

Some materials used in the study for the certification:
- Primary resource: `AWS Web Documentation`.
- Course: [Udemy - AWS Certified Cloud Practitioner](https://www.udemy.com/course/aws-certified-cloud-practitioner-new).
- Simulations: There are some books on the internet with lots of questions to practice.
- Also created some [Anki](https://apps.ankiweb.net) Cards to help remembering all the names an acronyms.
